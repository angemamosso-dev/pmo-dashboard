ⓘ Comment utiliser ce tableau ?

% Affecté (bloc bleu) = la part du temps de la ressource nominalement assignée à ce projet.

% Chargeabilité (bloc orange) = pour ce même projet, la part de cette affectation que le travail réellement réalisé couvre — 100 % veut dire que l'activité couvre exactement l'affectation sur ce projet ; 50 % = seule la moitié est couverte ; 150 % = dépassement sur ce projet précis. C'est un ratio, toujours relatif au % Affecté de la même case, jamais une valeur indépendante.

Chargeabilité totale = pour chaque projet, ce ratio est converti en temps réellement absolu (ratio × Affecté de ce projet), puis additionné sur tous les projets de la ressource — directement comparable au Total affecté. Écart = Chargeabilité totale − Total affecté.

Seuils de statut : Sous-utilisé < 70 % · Optimal 70–100 % · Tendu 100–115 % · Surcharge > 115 %.

Tout est modifiable directement dans le tableau : nom, type et rôle de chaque ressource, nom et phase de chaque projet, et bien sûr les %. Utilise la poignée ⠿ pour glisser-déposer une ressource ou un projet et changer son ordre. « Gérer les listes » permet d'ajouter/renommer/retirer les Types et les Phases proposés dans les menus déroulants. Le ✕ retire une ressource ou un projet du tableau.

Les données sont sauvegardées automatiquement dans ce navigateur. Le menu « Exporter » propose une sauvegarde JSON (à réimporter plus tard ou sur un autre poste), un export CSV, un classeur Excel, une image PNG et un rapport imprimable qui s'ouvre dans un nouvel onglet.
